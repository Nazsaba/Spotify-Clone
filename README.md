# Spotify-Clone
A simple and responsive Spotify UI clone built using HTML, CSS, and JavaScript.

  Project Overview

This project is a front-end clone of Spotify’s user interface.
It includes a music player layout, sidebar navigation, playlists section, and interactive play controls.

This project is perfect for practicing:
. HTML structure
. Advanced CSS styling (Flexbox, Grid, Positioning)
. JavaScript for audio controls
. Responsive web design

  Tech Stack

HTML5 – Page structure

CSS3 – Styling, layout, responsiveness

JavaScript (Vanilla JS) – Music player functionality
